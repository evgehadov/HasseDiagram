# HasseDiagram

Учебный проект по подготовке диаграмм Хассе для различных типов данных и реальный пример практического применения диаграммы Хассе.

Проект реализует построение и хранение диаграмм Хассе с различными типами и правилами упорядочивания.

---

## 📌 Основные возможности

- Построение диаграмм Хассе для стандартных типов данных:
  - INT
  - STRING
  - SET_INT
  - POINT2D
- Визуализация диаграмм с последующим сохранением на компьютер файлов типа .png и .dot
- Поддержка своего собственного типа при условии достаточного описания структуры
- Построение дерева подпоследовательностей для определения выравниваний для белковых аминокислотных последовательностей
- Определение схожести последовательностей через таблицы выравниваний BLOSUM62

---
## 📂 Структура проекта

Проект расположен в **одной ветке** и имеет следующую структуру:

```text
.
├── Graph/                 # папка для сохранения всех визуализаций
│   ├── screenshot.png
│
├── cmake-build-debug/
├── std_image_write.h      # Библиотека для работы с текстом для OpenGL
│
├── ITypeHandler.h         # Виртуальный класс для работы со всеми типами
├── SimpleTypeHandler.h    # Производный класс с реализацией всех базовых типов
├── HasseBuilder.h         # Класс для получения ребер на основе правил сравнения
├── HasseDiagram.h         # Класс диаграммы Хассе
├── TypeRegistry.h         # Класс необходимый для сбора всех имеющихся типов для предложения в консоль
├── AminoAcids.h           # Работа с аминокислотными остатками
├── AppCommon.h            # Основыне функции для работы с консолью и отслеживанием действий пользователя
├── BLOSUM62.csv           # Таблица выравниваний для белковых последовательностей
├── Draw.h                 # Визуализация диаграмм Хассе с последующим сохранением
├── Tests.h                # Реализация тестов для различных типов данных
├── CMakeLists.txt         # Сборщик проекта
├── main.cpp               # Точка входа
└── README.md
